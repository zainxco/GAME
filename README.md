# لعبة لاسا — Sakura Combat

لعبة قتال ثلاثية الأبعاد باستخدام Three.js. تحتوي على مهمتين متتاليتين، وتدعم الكمبيوتر والهاتف.

## المهمات

- **المهمة ١ — احمِ القرية:** اهزم ٨ أعداء. تظهر رسالة «قتلت كل اعداء لاسا» عند الفوز.
- **المهمة ٢ — حصار الغروب:** اضغط «ابدأ المهمة الثانية» بعد الفوز. واجه ١٠ حراس أسرع وزعيم الحصار. لدى الزعيم شريط صحة وضربة أرضية واسعة؛ انتبه إلى الدائرة الحمراء قبل ضربته.
- بعد خسارة أي مهمة، يمكنك إعادة المحاولة فيها. بعد الفوز بالمهمة الثانية يمكنك البدء من الأولى.

## التحكم

| الحركة | الكمبيوتر | أندرويد |
| --- | --- | --- |
| الحركة | WASD أو الأسهم | أزرار الاتجاه |
| هجوم السيف والضربات المتتالية | J | هجوم |
| التفادي | K | تفادٍ |
| القفز | Space | قفز |
| الجري | Shift | جري |
| تدوير الكاميرا | اسحب بالماوس أو Q / E | اسحب المشهد |

تتضمن الحركة ضربات سيف متنوعة، أثراً للسيف، ومؤثرات للإصابة والهبوط، بالإضافة إلى حركات مشي وضرب وتراجع وسقوط للأعداء. يجري التفادي لمدة قصيرة ويتطلب انتظاراً قبل استخدامه مجدداً.

## التشغيل والنشر

يُقدَّم هذا المجلد كموقع ثابت. عند توفر Python شغّل `python -m http.server 8000` ثم افتح `http://localhost:8000`. يُنشر الموقع من الفرع `main` والمجلد `/ (root)` عبر GitHub Pages.

مكتبة Three.js 0.160.0 محفوظة في `three.module.js`، وترخيصها في `THREE-LICENSE.txt`؛ لا تحتاج اللعبة إلى تحميل صور أو مكتبات خارجية أثناء اللعب.
