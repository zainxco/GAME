# لعبة لاسا — Sakura Combat

لعبة قتال ثلاثية الأبعاد مبنية باستخدام Three.js، تدعم الكمبيوتر وأزرار اللمس على أندرويد.

اهزم الأعداء الثمانية لتظهر رسالة الفوز: **قتلت كل اعداء لاسا**.

## التحكم

- WASD أو الأسهم: الحركة.
- J: الهجوم بالسيف. اضغط باستمرار للضربات المتتالية.
- Space: القفز.
- Shift: الجري.
- اسحب الشاشة أو الماوس: تدوير الكاميرا.
- Q و E: تدوير الكاميرا، وعجلة الماوس لتغيير المسافة.
- الهاتف: أزرار الحركة والهجوم والقفز والجري على الشاشة.

## التشغيل

هذه الملفات موقع ثابت؛ يجب تقديمها عبر خادم ويب يدعم JavaScript modules. مثال عند توفر Python:

```sh
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## GitHub Pages

من Settings → Pages اختر Deploy from a branch، ثم الفرع main والمجلد / (root).

## الملفات

- index.html: واجهة اللعبة.
- game.js: العالم والشخصية والأعداء والقتال.
- style.css: التنسيق وأزرار الهاتف.
- three.module.js: Three.js 0.160.0، محفوظ محلياً.
- THREE-LICENSE.txt: ترخيص مكتبة Three.js.

لا تحتاج اللعبة إلى تحميل صور أو مكتبات خارجية أثناء اللعب.
